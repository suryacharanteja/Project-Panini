# PANINI Brand Guidelines

## Brand Overview
**PANINI** - A Voice-First Windows Assistant

An intelligent, voice-activated personal assistant designed for Windows platforms. The brand identity reflects cutting-edge AI technology through a sophisticated geometric network icon symbolizing neural connectivity and intelligent processing.

- **"PANINI"**: Bold, uppercase, tracking +2px
- **"VOICE-FIRST WINDOWS ASSISTANT"**: Light weight, all-caps, smaller size

## Icon Design Guidelines

### Visual Elements
1. **Geometric Network Pattern**: Connected nodes representing AI neural networks
2. **Question Mark Symbol**: Central element symbolizing inquiry and intelligence
3. **Gradient Application**: Smooth copper-to-gold gradient across all icon variants
4. **Connection Lines**: Subtle wireframe style connecting nodes

### Icon Variations to Generate
- **Favicon (16x16px, 32x32px)**: Simplified mark, minimal detail
- **App Icon (64x64px, 128x128px, 256x256px)**: Full detail, optimal readability
- **Taskbar (16x16px, 32x32px)**: Monochromatic and gradient versions
- **Notification (32x32px, 48x48px)**: Slightly simplified
- **Large Format (512x512px)**: Maximum detail for high-DPI displays

### Background Considerations
- **Dark Backgrounds**: Use full gradient copper to gold
- **Light Backgrounds**: Use darker copper tones or monochromatic versions
- **Transparent Backgrounds**: Maintain full icon with drop shadow for depth

## Logo Usage

### Clear Space
Minimum clear space around logo: 20% of the logo's height

### Size Guidelines
- **Minimum Size**: 100px (width) for digital use
- **Print Minimum**: 0.5 inches (width)
- **Recommended Display Size**: 300px+ for web headers

### Do's and Don'ts

✅ **Do:**
- Maintain aspect ratio when scaling
- Use on dark backgrounds for optimal contrast
- Apply consistent spacing around the logo
- Use the official color palette

❌ **Don't:**
- Stretch or distort the logo
- Change the color palette without approval
- Rotate or flip the logo
- Add effects that obscure the design
- Use on backgrounds with insufficient contrast

## File Formats

### Provided Assets
- **JPG**: High-quality raster for web and marketing
- **Recommended**: Export to PNG (transparency), SVG (scalability), and ICO (Windows icons)

### Export Specifications
- **PNG**: 32-bit RGBA for transparency
- **SVG**: Vector format for infinite scaling
- **ICO**: Windows icon format for system integration
- **JPG**: RGB color space, 85% quality minimum

## Accessibility

### Contrast Ratios
- Copper/Gold on Dark Navy: WCAG AA compliant (>7:1)
- Suitable for color-blind users (distinct brightness difference)

### Icon Recognition
- Clear geometric form identifiable at small sizes
- Central question mark remains visible even at 16x16px
- Network pattern aids in AI/intelligence communication
